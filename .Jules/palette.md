## 2026-08-08 - Add Tooltips to Icon-Only Buttons
**Learning:** Avalonia UI `ToolTip.Tip` attribute provides an easy way to make icon-only buttons (like '+', '-', 'x', '→') accessible to users by providing a descriptive hover text, enhancing the overall micro-UX and accessibility of the interface.
**Action:** Always verify if icon-only buttons have a corresponding `ToolTip.Tip` attribute in Avalonia .axaml files. If they don't, add one with a concise and clear description of the button's action.
