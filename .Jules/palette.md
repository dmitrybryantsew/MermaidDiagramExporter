## 2026-08-09 - Add ToolTips to Icon-Only Buttons
**Learning:** Adding descriptive `ToolTip.Tip` attributes to icon-only buttons in Avalonia XAML improves accessibility and clarity for users, and is a simple, effective UX improvement pattern in this app.
**Action:** Always verify that buttons containing only icons or symbols (e.g., `+`, `−`, `✕`) have clear `ToolTip.Tip` attributes in Avalonia UI components.
