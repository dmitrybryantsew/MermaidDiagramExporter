## 2024-05-24 - Add tooltips to icon-only buttons
**Learning:** Icon-only buttons (like zoom controls) in desktop apps need explicit tooltips for both accessibility (screen readers) and general UX (clarity). The Avalonia UI framework provides `ToolTip.Tip` for this purpose.
**Action:** Always verify that icon-only buttons have descriptive tooltips (`ToolTip.Tip`) in Avalonia applications.
